# 🚀 Using GitHub Copilot

A short, picture-led guide for **everyone** — from first-day beginners to power users.
Each page is small, has screenshots, and uses simple words. Read top to bottom, or jump to what you need.

> 💡 **One big idea:** GitHub Copilot is an **AI helper inside VS Code**. You chat with it. It can read your code, edit files, run commands, and do whole tasks for you. You stay in control — you choose how much freedom it gets.

## ⚡ The 60-second start

1. Open the Chat panel — click the Copilot icon in the title bar.
2. Start a **fresh chat** for each new task — chevron → **New Chat Editor** (opens as a tab).
3. Type what you want in plain words and send it.
4. Leave the **Agent** mode on so it can actually do the work.
5. Watch the steps. Approve when it asks. Done.

![How to open a new chat editor](assets/01-open-new-chat.png)

> ✅ **Best habit:** one task = one new chat editor. A fresh chat has empty memory, so the AI is not confused by old work.

---

## 🗣️ Talk to it like a person

You do **not** need special words. Just be clear.

- *"Find where we read the MQTT port and add a log line."*
- *"Run the tests and fix anything that fails."*
- *"Explain this file to me in simple terms."*

The clearer you are, the better the result. If you are not sure, ask it to make a plan first.
