# Daily Standup

Short synchronization meeting held every working day.

## Details

| Field | Value |
|-------|-------|
| **Cadence** | Daily |
| **Duration** | 15 min per team |
| **Scope** | Per [team](../../foundation/teams/README.md) |

## Format

Each team runs its own standup:

1. [Team Alpha](../../foundation/teams/team-alpha/README.md) — 09:30–09:45
2. [Team Beta](../../foundation/teams/team-beta/README.md) — 09:45–10:00

## Participants

All members of the respective [team](../../foundation/teams/README.md).
[Taylor Morgan](../../people/taylor-morgan/README.md) joins as manager.
