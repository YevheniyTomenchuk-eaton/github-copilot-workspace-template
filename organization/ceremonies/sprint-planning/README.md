# Sprint Planning

Planning meeting at the start of each sprint.

## Details

| Field | Value |
|-------|-------|
| **Cadence** | Per sprint |
| **Duration** | 1–2 hours |
| **Scope** | All teams |

## Format

Teams review the backlog, estimate items, and commit to the sprint scope.

## Participants

All members of [Team Alpha](../../foundation/teams/team-alpha/README.md) and
[Team Beta](../../foundation/teams/team-beta/README.md), facilitated by
[Taylor Morgan](../../people/taylor-morgan/README.md).
