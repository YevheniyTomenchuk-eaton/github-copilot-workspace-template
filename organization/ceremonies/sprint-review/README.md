# Sprint Review

Demo and review meeting at the end of each sprint.

## Details

| Field | Value |
|-------|-------|
| **Cadence** | Per sprint |
| **Duration** | 1 hour |
| **Scope** | All teams |

## Format

Teams demo completed work and gather feedback for the next sprint.

## Participants

All members of [Team Alpha](../../foundation/teams/team-alpha/README.md) and
[Team Beta](../../foundation/teams/team-beta/README.md), plus any stakeholders.
